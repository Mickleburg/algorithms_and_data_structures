# Задачи с воркшопа по динамическому программированию и BFS


## 1. Longest Increasing Subsequence

Дан массив целых чисел `nums`. Нужно вернуть длину самой длинной строго возрастающей подпоследовательности.

Подпоследовательность - это элементы исходного массива, взятые в исходном порядке, но не обязательно подряд.

Пример:  
`nums = [10, 9, 2, 5, 3, 7, 101, 18]`  
Одна из самых длинных возрастающих подпоследовательностей: `[2, 3, 7, 101]`  
Её длина = `4`.

**Требование:** решение должно использовать динамическое программирование, где `dp[i]` — длина самой длинной возрастающей подпоследовательности, которая заканчивается в элементе `nums[i]`.

Решение должно работать за `O(n^2)` по времени и `O(n)` по памяти.

Источник задачи: https://leetcode.com/problems/longest-increasing-subsequence/description/

## 2. 01 Matrix

Дана бинарная матрица `mat` размером `m x n`, состоящая из `0` и `1`. Нужно вернуть матрицу такого же размера, где для каждой клетки указано расстояние до ближайшего нуля.

Расстояние между двумя соседними клетками равно `1`. Соседними считаются только клетки, имеющие общую сторону: сверху, снизу, слева или справа. Ходить по диагонали нельзя.

Пример:  
`mat = [[0,0,0],[0,1,0],[1,1,1]]`

Ответ:  
`[[0,0,0],[0,1,0],[1,2,1]]`

**Требование:** решение должно использовать BFS от всех нулей одновременно. Все клетки с `0` добавляются в очередь как стартовые точки с расстоянием `0`, после чего расстояния до остальных клеток обновляются волной.

Решение должно работать за `O(m * n)` по времени и `O(m * n)` по памяти.

Источник задачи: https://leetcode.com/problems/01-matrix/description/
